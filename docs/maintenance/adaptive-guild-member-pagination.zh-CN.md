# 自适应社区成员分页

启动成员加载使用不相交区间，数据库页最多 1000 行，查询 1001 行判断后续页。现有并发配置启用并行加载时，页和端点探针共享最多四个槽；同一时刻最多一个探针，整个加载最多 `槽数 × 64` 次探针。探针按同一区间顺序读取 ASC / DESC 各一个 ID，不执行 COUNT，不用端点缩短开放根区间。

API 返回映射前数据库页的首尾 ID 和行数。未知用户引用可在映射中被过滤，但游标仍覆盖原数据库页；网关验证范围、严格递增的成员 ID、行数和游标，不允许半成品发布。ID 全程保持 bigint / Erlang 整数 / 十进制文本，不经过浮点数。

旧 API 完全不提供三个覆盖字段时，协调器先丢弃所有已收集分片、停止其余任务，再从开放根区间使用旧串行 `guild_collection` 协议重新加载。仅缺少部分字段或字段畸形属于错误，不以兼容模式掩盖。旧串行接口的畸形或空映射续页仍可能明确失败，不发布不完整角色索引。

探针失败只取消拆分提示，继续原区间分页。页永久错误、重试耗尽、截止时间或调用者退出均停止整组。完成全部成员页后才发布 `members_complete`。加载仍为弱一致 keyset 视图，不能保证加载中新增且已落在游标之前的键可见；这不是数据库快照。

部署先升级 API/schema，再升级 Gateway；混合节点可安全回退但不能保证性能相同。该实现不依赖观测模块、NIF 或设备资格缓存。单元测试与模拟 SQL 验证不能替代 PostgreSQL/Cassandra 实库、滚动发布和完整服务构建验证；本次交付验证详见交付报告。
