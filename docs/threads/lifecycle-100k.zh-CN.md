# 有界帖子生命周期

guild_thread_store 维护派生 {mc, ThreadId} 计数，重复加入/删除保持幂等。缺计数返回 unknown；导入按真实关系重建，消息热路径不得扫描全部关注者补计数。ordered prefix 每页最多 1000 个标识，清理/恢复采用 512 条中间页。冷加载逐帖最多 200 页，游标不前进或不完整必须失败。

生命周期准备在 owner 外建立 protected ETS 快照，核实版本、精确人数、严格标识顺序与 keeper 拥有关系。每 guild 至多四个操作，就绪快照最多保留十分钟，活跃快照阻止 handoff。API 原 5 秒预算保持，准备限定 4 秒，失败向上传播。

冻结后的完整 DB 成员保留到 owner 删除确认。keeper 丢失仅能在原冻结版本/人数仍一致时重建同票据。owner 确认消费票据，API 先持久化 delete_dispatched 再清理，最后频道/state 同 atomic batch 删除。持久确认前失败可能重复幂等删除事件；不是设备实收或 exactly-once 保证，也没有自动后台恢复扫描器。

取消归档只暂存该帖子事件，至多 1024 条/4 MiB。精确票据超时、溢出或加载失败进入既有完整重载，不发布半成员状态。删除分发仍按准备上下文复查当前权限，不把完整关注列表装入事件。迁移、旧候选部分 purge 限制、部署与回退详见双语维护说明。
