# 论坛帖子发现与事件订阅

[English](FORUM_DISCOVERY.md)

关注帖子决定自动同步和普通事件投递，不是主动列出、搜索或读取帖子的额外权限要求。频道权限、私有线程、年龄限制及消息历史访问规则仍然生效。

## 目录接口

`GET /channels/:channel_id/threads/directory` 按创建时间倒序列出单个论坛或媒体频道的帖子，不依赖搜索服务，也不读取整个群的所有活跃帖子。

| 参数 | 含义 |
| --- | --- |
| `archived` | `false` 查询活跃帖，`true` 查询归档帖；默认 `false`。 |
| `tag`、`tag_setting` | 沿用论坛标签筛选规则。 |
| `limit` | 普通页大小，范围 1–100，默认 50。 |
| `cursor` | 上一页返回的不透明续页令牌。 |

响应包含 `threads`、调用者自己的 `members` 记录、`pinned_thread`、`next_cursor` 和 `has_more`。活跃目录首页单独返回有权查看的活跃置顶帖，不占普通页额度；它也可能出现在 `threads` 中，客户端按帖子 ID 去重。后续页返回 `pinned_thread: null`，不替换首页的置顶结果。

单次请求最多检查 1000 条索引记录，每批最多 100 条。归档、失效、筛选不匹配或不可见记录可能产生短页乃至空页。**只要 `next_cursor` 非空就可以继续**；`has_more` 表示仍有扫描工作，不保证后面一定存在更多可见帖子。游标有效期为 15 分钟，可跨 API 实例使用，绑定调用者、群、父频道及筛选条件。每页都重新检查权限。提交的游标记录不存在、过期或不匹配时返回指向 `cursor` 字段的校验错误，客户端重新取得首页；不提交游标则正常读取首页。依赖故障不会退化为全量目录查询。

文字搜索继续使用 `/channels/:channel_id/threads/search`。保留后端旧搜索排序参数和旧归档列表的分页语义。客户端普通目录按创建时间排序，不再提供最后活跃时间选项。

## 加载与访问

登录和重连保留原有关注帖子初始化；进入论坛才请求目录。目录卡片不会建立浏览租约或自动关注。显式刷新、页面导航或用户自己的操作完成后更新页面及预览，不新增实时目录订阅。权限撤销和已知删除仍会及时清除不可访问内容。

主动目录、搜索、归档、帖子资料、未读和成员名单查询不要求关注。批量预览省略不可访问的帖子 ID。首条消息仍遵循消息历史权限和截止时间，能看到帖子不等于可以读取全部历史。已缓存与未缓存帖子的未读查询统一走 API 的有界用户授权路径。

普通消息事件仍要求关注或已接受的浏览租约，保留已有的直接提及权限例外。提及自动加入逻辑不变；浏览到期、恢复、权限检查和会话去重继续生效。

## 升级顺序

先部署支持目录及未读用户授权的 API，再部署配套 Gateway，最后更新客户端。不要将新的 Gateway 未读行为与不验证请求用户的旧 API 混用。无需数据库迁移或重建搜索索引。移除 API 目录能力前，先回退客户端。
